## 插件与原版的差异

原版 `SettingsView/components/PluginSettings.vue` 和 `PluginsView/components/PluginConfigItem.vue` 使用插件元数据生成 Switch、Radio、Input 等控件。本分支保持这套表单逻辑，1.3.0 增加 TextArea，便于编辑 hosts 和规则 JSON，并提供后端类型校验、串行保存和 revision 冲突提示。参数保存失败会保留草稿；不以成功提示掩盖失败。

GUI 原版的插件运行环境包含 Wails、前端 Store、窗口和文件等 API。本分支通过 Goja 执行后端 JS，独立仓库维护适配源码；浏览器关闭后，订阅定时任务仍能触发。手动订阅处理选择现有缓存，不隐式下载订阅或重启核心；声明 `manual_target: "diagnostic"` 的插件直接运行 `onRun()`，不选择订阅、不改缓存，显示报告和日志。接口和兼容边界见 [插件说明](plugins.md)。

GUI 的索引/重命名操作还需适应 WebUI 的订阅 ID 引用。当前内置插件保留节点身份并改写内部出站引用，避免重新更新订阅后配置中已选节点丢失。自定义脚本如果主动丢弃内部身份字段并创建全新节点，首次改名可能被视为新节点。

三种命名策略通过 `conflicts` 互斥。旧安装若同时启用了防代理重名、更好的代理名称显示和美化节点名称中的多个，请在更新插件前先禁用多余策略。主程序先升到 1.3.0，再更新插件；更新保留参数和启停状态，遇到冲突明确报错，不静默选择策略。

路由器透明代理、独立代理端口、出站链、配置覆盖、规则集引用、Hosts DNS、AdGuardHome 对接及核心 URLTest 均只生成配置。默认参数不会启用这些改动，需先填写设备实际接口、端口、标签并预览。透明代理脚本不写系统防火墙、不替 dnsmasq；启动核心后，sing-box 才按配置执行自动路由和重定向。AdGuardHome/FRP 等独立进程应由 procd/systemd 管理，不移植桌面下载器、PID 文件和进程守护循环。

自动测速选择使用核心 URLTest，不等同于原插件的 EWMA 评分、按错误日志阈值切换或有序故障转移。流媒体检查仅报告可达性或明确的区域拒绝，不能凭 HTTP 200 宣称完整解锁。下载测速是当前出口的有限样本，不是批量切换节点的全线路排名。

普通钩子没有网络 API；手动诊断只提供受限 GET/HEAD 和最多一次下载采样，不提供 Shell、文件或任意请求头。管理员主动运行的诊断可访问所选内网地址，没有域名白名单；Goja 的时限和数据限额也不是强内存隔离，仍需只安装可信脚本。

## 核心与服务生命周期

GUI 切换 Stable/Alpha 时通常立即重启。WebUI 延续直接上游的自动重启设置：关闭自动重启时，保存分支或参数后显示待重启入口；管理员决定何时中断当前连接。核心下载成功也需要重启才进入新版本，并保留本地备份用于回滚。

路由器上“服务开机启动”由 OpenWrt procd 或系统 systemd 管理；“程序启动时开启核心”指 WebUI 服务启动后是否启动 sing-box，两者是不同操作。

不恢复桌面托盘、窗口大小/标题栏、最小化、窗口内容保护、Windows 提权、多桌面实例、打开本机文件夹和设置访问者电脑系统代理/DNS。浏览器管理的对象始终是部署 WebUI 的设备。

## 网络请求边界

请求代理影响 WebUI 后端的订阅、规则集、版本检查、下载和插件目录请求。诊断可遵循这项设置，或显式选择直连/运行核心代理；诊断不会携带 GitHub Token 或使用下载镜像。它与 sing-box 对 LAN 客户端的透明代理规则不同，不会自动调整防火墙、dnsmasq、DHCP 或 TUN。

“环境代理”读取路由器服务的 HTTP_PROXY/HTTPS_PROXY/NO_PROXY 等环境，而不是访问页面的电脑；可在 procd/systemd 服务环境中设置。“核心代理”仅使用当前实际运行实例的 HTTP/mixed 入站及其认证；仅有 TUN 时没有可用 HTTP 代理，会明确报错，不静默直连。自定义启动参数加载额外配置文件时，也不会猜测实际代理端点。

镜像模板使用 `https://example.com/{url}`，默认不配置第三方地址。镜像只替换公开 GitHub release/archive 下载，不替换 GitHub API、插件原始源码地址或用户订阅；这些请求仍遵从所选请求代理。API 令牌不会交给镜像。

当前界面内置简体中文和英文；原版额外语言下载及目录操作尚未移植。本轮没有在真实路由器上测试；静态跨架构构建和自动化测试不能替代 GL-MT3600BE 等真实固件上的 TUN、转发、DNS 与防火墙验证，部署要求见 [路由器说明](routers.md)。
