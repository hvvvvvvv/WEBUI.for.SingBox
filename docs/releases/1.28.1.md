# 1.28.1

正式版号与官方 GUI.for.SingBox 最新稳定版一致，本次重新构建并发布全部累计修复。

- 恢复官方配置、规则、插件、核心设置和空状态的操作方式，统一深浅主题与登录页，完善手机排版和浏览器本地背景设置；修复空插件页切换闪烁及下拉菜单错位，网络请求设置恢复分段按钮与点击编辑。
- 增加访问密码、TOTP、恢复码和会话撤销；修复凭据解析、并发编辑、快速保存及 WebSocket 生命周期问题。
- 新配置默认 TUN，内置六份完整初始规则，新安装及使用原默认来源的旧配置不再依赖首次规则下载；默认每 24 小时更新，失败保留有效规则。完善 DNS/HTTP 客户端适配、启动等待、核心重启恢复及停止竞态处理。
- 插件仅从独立的 [WEBUI.for.SingBox-Plugins](https://github.com/Ghostdehole/WEBUI.for.SingBox-Plugins) 按需安装，提供 14 个职责分离的插件，主程序不打包脚本。
- 修复脚本取消与资源限制、订阅和规则集保存失败回滚、敏感 URL 日志、更新并发及核心缓存处理，减少后台重复请求和内存占用。
- 完善 OpenWrt procd、容器入口和多架构构建，更新依赖并同步文档。

已通过前端 321 项测试、类型检查、构建、lint、Go 回归、Linux race、跨平台构建、sing-box 1.14.4/1.15.0-alpha.13、容器、OpenWrt ARM64 模拟、隔离 DNS/TUN 及官方 GUI 对照检查。未进行 GL-MT3600BE 实机或真实 AdGuard Home 验证。详细证据见 [集成与验证记录](https://github.com/Ghostdehole/WEBUI.for.SingBox/blob/main/docs/upstream-integration.md)。

**升级：**本次为同版本重新发布，旧 `1.28.1` 用户需要手动下载新安装包，停止服务后替换程序，再启动。升级前备份原程序和整个 `data/` 目录；ZIP 包含程序、许可证与规则源码，请一并解压保留，正常升级不要删除 `data/`。核心和已安装插件分别更新。容器用户应重新拉取镜像并重建容器，保留原数据卷。

初始规则保护适用于默认六个标准来源；自定义来源、显式初始文件和用户指定的更新策略保持不变。
